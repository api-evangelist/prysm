# Prysm (Motherson Prysm, Inc.)

> Prysm builds large-format interactive display hardware and the Prysm Application Suite, a
> cloud-hosted visual collaboration and digital-workplace platform. Founded in 2005 in Silicon
> Valley as Spudnik by Amit Jain and Roger Hajjar, the company invented and patented Laser
> Phosphor Display (LPD) technology. It merged with Anacore in 2014 to add a multi-source
> interactive canvas, and became part of the Motherson Group in 2025.

Prysm publishes **no public API**: there is no developer portal, no API reference, and no
machine-readable specification (OpenAPI, AsyncAPI, GraphQL SDL, Protobuf, WSDL, MCP manifest or
A2A agent card) at any Prysm host. A "Prysm API" early preview was announced on 14 June 2017 for
building custom applications on the digital workplace platform; no public documentation for it
exists today. Treat Prysm as an end-user product company, not an API provider.
